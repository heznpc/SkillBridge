SkillBridge låter dig också spara, läsa om, exportera och förbättra termer i kursen.

01

Översätt hela sidan

Översätt rubriker, text, navigering samt kommentarer och undertexter som stöds på plats.

02

Läs offline från cache

Redan översatt text går att läsa från webbläsarens cache när anslutningen bryts.

03

Lokala studieverktyg

Minneskort, bokmärken, anteckningar, senaste lektioner, framsteg, innehållsförteckning och PDF-export.

04

Återkoppling om översättning

Rapportera ett stycke, granska rättningen, tillämpa på exakt matchning eller ångra.

05

Undertexter och mörkt läge

06

Provskydd

07
