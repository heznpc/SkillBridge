01지원되는 강의 안에서 시작됩니다

강의를 떠나지 않고, 필요한 언어로 읽으세요.

SkillBridge는 지원되는 AI 강의의 원래 화면에 번역과 학습 도구를 더합니다. 페이지를 복사하거나 다른 탭으로 옮길 필요가 없습니다.

버전 안내 현재 페이지는 GitHub 소스 v4.2.0을 기준으로 합니다. Chrome 웹 스토어에는 아직 이전 버전 v1.0.1이 게시되어 있으며, 새 버전의 CWS 배포는 개발을 마친 뒤 진행합니다.검증 경계 자동 테스트는 Academy 경로와 Tutor 전송을 확인합니다. 로그인 상태의 실제 강의 제출 화면과 Puter 왕복은 최종 배포 검증 항목으로 남아 있습니다.

01

지원되는 강의를 엽니다

평소처럼 AI Academy 수업을 엽니다. 별도 작업 공간이나 복사·붙여넣기는 필요하지 않습니다.

02

지구본 메뉴에서 언어를 선택합니다

언어를 고르면 현재 강의의 읽을 수 있는 텍스트가 같은 자리에서 바뀝니다.

03 / 문맥은 그대로

번역 때문에 다른 탭으로 이동하지 않습니다.

강의 목록, 본문, 복습 도구가 한 흐름 안에 남아 있어 읽던 자리로 돌아갈 필요가 없습니다.

04 / 기능 한눈에 보기

읽기부터 복습과 피드백까지 한곳에서.

번역만 바꾸는 확장 프로그램이 아닙니다. 강의를 읽고, 저장하고, 다시 보고, 번역을 개선하는 데 필요한 도구를 함께 제공합니다.

01

전체 페이지 번역

강의 제목, 본문, 목록, 탐색 메뉴와 지원되는 댓글·자막을 강의 안에서 번역합니다.

02

오프라인 캐시

이미 번역한 문장은 브라우저 캐시에 남아 연결이 잠시 끊겨도 다시 읽을 수 있습니다.

03

로컬 학습 도구

플래시카드, 북마크, 노트, 최근 강의, 진도, 목차와 PDF 내보내기를 제공합니다.

04

번역 피드백과 교정

문제가 있는 번역을 리포트하고, 검토한 교정안을 적용하거나 되돌릴 수 있습니다.

05

자동 자막과 다크 모드

지원되는 강의 영상 자막을 번역하고, 어두운 화면에서도 학습할 수 있습니다.

06

시험 안전 장치

퀴즈 선택지는 번역하지 않고, 인식된 감독형 시험에서는 확장 프로그램을 끕니다.

07

스마트 감지와 단축키

브라우저 언어와 SPA 강의 이동을 감지하고, 자주 쓰는 도구를 키보드로 엽니다.

08

정확한 전문 용어

Premium 사전과 보호 용어 복원으로 브랜드명과 AI 용어를 지킵니다.
