Versionsoplysninger Siden viser GitHub-koden v4.2.0, ikke en indsendelse til Chrome Web Store. Butikken installerer stadig v1.0.1; næste udgivelse afventer færdig udvikling. I USA er manuel installation via GitHub tilgængelig.Omfang af kontrol Automatiske tests dækker Academy-navigation og Tutor-kommunikation. 01

Åbn en understøttet lektion

Åbn AI Academy som normalt, uden ekstra arbejdsområde eller kopiering og indsættelse.

02

Vælg sprog i globusmenuen

Lektionsteksten ændres på stedet, så snart du vælger sprog.

03 / Konteksten bevares

Oversættelsen sender dig ikke til en anden fane.

Kursusliste, tekst og repetition bliver samlet, så du ikke skal afbryde læsningen for at finde tilbage.

04 / Alt på ét sted

Fra læsning til repetition og feedback.

SkillBridge lader dig også gemme, genlæse, eksportere og forbedre udtryk i kurset.

01

Oversættelse af hele siden

Oversæt overskrifter, tekst, navigation samt understøttede kommentarer og undertekster på stedet.

02

Læs offline fra cache

Allerede oversat tekst kan læses fra browserens cache, når forbindelsen forsvinder.

03

Lokale studieværktøjer

Huskekort, bogmærker, noter, seneste lektioner, fremskridt, indholdsfortegnelse og PDF-eksport.

04

Feedback på oversættelser

Rapportér et afsnit, gennemgå rettelsen, anvend på præcist match, eller fortryd.

05

Undertekster og mørk tilstand

Oversæt understøttede undertekster, og studér med en mørk visning.

06

Beskyttelse ved prøver

Svarmuligheder ændres ikke; genkendte prøver under opsyn deaktiverer udvidelsen.

07

Registrering og genveje

Registrér browsersprog og SPA-lektionsskift, og åbn værktøjer med tastaturet.

08

Præcis terminologi

Premium-ordbøger og gendannelse bevarer mærkenavne og AI-fagudtryk.
